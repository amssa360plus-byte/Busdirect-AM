# Busdirect-AM

Application web et reservation de places de bus pour le trajet **safi -Marrakec** (20placem 80 DH par place).

## fonctionnalites 

- resrver une place (chiox automatique de la premier place libre si aucune n'est choisie)

- modifier ou annuler une reservation
- Nombre de places occupees et total en DH en direct 

- resirvation sauvegardees dans le navigateur  **localStorage**

- Design responsive mobile

CSS 
tailwind 
JS
